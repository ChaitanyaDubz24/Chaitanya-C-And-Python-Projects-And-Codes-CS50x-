# Chaitanya's Portfolio

A collection of my work in software, electronics, and mechanical design. I'm a 17 year old second year Mechatronics Engineering student at the University of Waterloo, and most of what I build sits where those three areas meet, from full software products to physical robots to CAD. This repository brings that work together in one place.

## What's Inside

| Folder | What it is |
|--------|-----------|
| `project-joy-prototype/` | Joy, a companion platform for private adoption. Three connected interfaces, a family portal, an attorney console, and an 8-bit family website builder, built end to end in HTML and CSS. |
| `project-cherive-companion-app/` | Cherive, a cross-platform desktop pet. A customizable cat or dog that idles, reacts, and plays in your screen corner, with a step-away break reminder. Built in Python with PySide6, currently in active development. |
| `project-study-bot/` | Procrastinot, a study-companion robot that enforces focus. Runs Pomodoro cycles in C++, monitors attention with distance and camera sensors, and drives a reward catapult and a timed phone-lock enclosure. |
| `practice-codes-cpp/` | C++ practice and coursework, covering fundamentals through data structures and algorithms. |
| `practice-codes-python/` | Python practice, including CS50x problem sets. |
| `engineering-solidworks-designs/` | Parts and assemblies modeled in SolidWorks. |
| `engineering-autocad-drawings/` | Technical drawings drafted in AutoCAD. |

## Where to Start

If you're skimming, start with **Joy** and **Cherive**. Joy is a full multi-interface product for a real, sensitive problem space. Cherive is a from-scratch desktop app with transparent, always-on-top window handling. The rest shows range: robotics in C++, python, plus mechanical design in SolidWorks and AutoCAD.
