Low-fidelity HTML wireframes for **Joy**, a companion platform for private adoption in the US. Joy is maintained by adoption attorneys who provide the apps to their clients — adoptive families and birth parents. It is not a legal case-management tool and gives no legal advice; all content reads as the attorney's vetted guidance.

## Interfaces

| Interface | Description |
|-----------|-------------|
| **Family UI** | Stage tracker, plain-language explainers, document checklists, and vetted resources. |
| **Attorney UI** | Case list, case detail with stage controls, resource curation, and family progress. |
| **8bit Website UI** | The website. |

## Viewing

Open any `.html` file in a browser to view the wireframe.
