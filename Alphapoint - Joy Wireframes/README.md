## Overview

This repository contains the low-fidelity HTML wireframes for Joy, a companion platform for private adoption in the United States. Joy is maintained by adoption attorneys, who provide the apps to their clients, including adoptive families and birth parents. The platform is not a legal case-management tool and does not provide legal advice. All content is presented as the attorney's vetted guidance.

These wireframes define the structure and layout of each interface before visual design and development begin. They exist to align on what appears on each screen and roughly where it sits, which is far faster and cheaper to revise at this stage than after the product is built.

## Interfaces

| Interface | Description |
|-----------|-------------|
| Family UI | The adoptive family app. Includes a stage tracker showing progress from home study to finalization, plain-language explainers for confusing terms, stage-by-stage document and task checklists, and a page of attorney-vetted resources. |
| Attorney UI | The attorney console. Includes a case list of all families and their current stage, a case detail view for setting and advancing each family's stage, a resource-curation screen for approving what clients see, and a progress overview. |
| 8bit Website UI | The public-facing website. |

## How the Code Works

Each wireframe is a self-contained HTML file that can be opened directly in a browser with no build step, server, or dependencies. The layouts use plain semantic HTML with a small amount of CSS to position elements. There are no frameworks and no JavaScript beyond what is needed for layout.

The wireframes are intentionally low fidelity. They rely on grey boxes and clearly labeled placeholders (for example, a box marked "family photo") rather than real images, color, or final styling. This keeps the focus on structure and content rather than visual polish.

## Viewing

Open any `.html` file in a browser to view the corresponding wireframe. No installation is required.
